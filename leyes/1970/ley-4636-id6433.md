# Ley N° 4636 — Reforma Código Municipal

> SCIJ: Vigente; Versión de la norma: 1 de 1.

Texto no disponible

###### Artículo 1º

Refórmase el artículo 187 del Código Municipal, ley

Nº 4574 de 4 de mayo de 1970, para que se lea así:

"Artículo 187.- Este Código entrará a regir el 1º de enero de

1971".
